语音启动活性诊断

仅允许 loopback。这里是开发用离线模拟，不是生产 App，也不验证声音自然度、可听性或音素嘴形。没有 Key、聊天/语音 API 或模型下载。

1. 无事件系统朗读 stub · 完全无声

用户点击后，临时吞掉本页 SpeechSynthesis 的 speak / cancel 调用，不产生任何 start / end / error 事件，也不调用真实系统声线。

使用生产控制器的原始启动截止时间，不加速计时。请等约 15 秒，看 preparing 是否退出、嘴形是否归零并显示停止提示。

准备读取生产截止策略……

本页不提供真实系统朗读模式。真实原生声线检查请另用 独立系统语音诊断页，不会自动打开或朗读。

2. 独立 PCM 正常路径 · 会播放音调

可选：用户点击后在本机生成 8 秒调制音调，通过生产控制器与真实 HTMLAudio 播放。它不是人声；cloud 状态只表示注入 PCM 的路径，不代表网络请求。

暂停和拖动只操作这个原生播放器，不伪造媒体事件。系统语音仍被本页 stub 隔离。
